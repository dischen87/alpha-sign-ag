# Sanity CMS Anleitung für Alpha Sign AG

## Einführung

Diese Anleitung erklärt, wie Sie Inhalte auf der Alpha Sign AG Website bearbeiten können, ohne Programmierkenntnisse zu benötigen.

---

## Zugang zum Sanity Studio

### URL
**https://alpha-sign.sanity.studio/**

### Anmeldung
1. Öffnen Sie die URL in Ihrem Browser
2. Melden Sie sich mit Ihrem Google- oder GitHub-Konto an
3. Falls Sie keinen Zugang haben, kontaktieren Sie den Administrator

---

## Übersicht der Bereiche

Nach der Anmeldung sehen Sie links das Menü mit folgenden Bereichen:

| Bereich | Beschreibung |
|---------|--------------|
| 📁 **Projekte / Portfolio** | Ihre Referenzprojekte und Case Studies |
| 🛠️ **Dienstleistungen** | Die angebotenen Services |
| 👥 **Team** | Team-Mitglieder |
| ❓ **FAQ** | Häufig gestellte Fragen |
| 📄 **Seiten** | Allgemeine Seiteninhalte |
| ⚙️ **Einstellungen** | Globale Einstellungen |

## Projekte bearbeiten

### Neues Projekt erstellen

1. Klicken Sie auf **"Projekte / Portfolio"** im Menü
2. Klicken Sie oben rechts auf das **"+"** Symbol oder **"Erstellen"**
3. Füllen Sie die Felder aus:

#### Pflichtfelder (rot markiert)
- **Project Title**: Titel des Projekts (Deutsch UND Englisch)
- **Slug**: URL-Pfad (z.B. `mein-projekt` → erscheint unter `/portfolio/mein-projekt`)
- **Main Image**: Hauptbild für die Projektübersicht

#### Empfohlene Felder
- **Client Name**: Name des Kunden
- **Excerpt**: Kurze Beschreibung (2-3 Sätze)
- **Completion Date**: Wann wurde das Projekt abgeschlossen?
- **The Challenge**: Welche Herausforderung hatte der Kunde?
- **Our Solution**: Wie haben Sie das Problem gelöst?
- **Results**: Die Ergebnisse (als Aufzählung)

#### Medien
- **Main Image**: Hochladen mit Klick auf "Select" → "Upload"
- **Project Gallery**: Mehrere Bilder für die Detailseite

#### Wichtig: Featured Project
- Aktivieren Sie **"Featured Project"**, wenn das Projekt auf der Startseite erscheinen soll

### Projekt veröffentlichen

1. Klicken Sie oben rechts auf **"Publish"** (grüner Button)
2. Das Projekt ist sofort auf der Website sichtbar
3. Falls Änderungen nicht erscheinen: Warten Sie 1-2 Minuten (Cache)

---

## Bilder hochladen

### Bildformate
- **Empfohlen**: JPG oder PNG
- **Maximale Größe**: 5 MB pro Bild
- **Empfohlene Auflösung**: Mindestens 1200px breit

### Hochladen
1. Klicken Sie auf das Bildfeld
2. Wählen Sie **"Upload"**
3. Ziehen Sie das Bild hinein oder wählen Sie es vom Computer
4. **Hotspot setzen**: Klicken Sie auf das Bild und setzen Sie den Fokuspunkt

### Tipp: Media Library
- Klicken Sie links auf **"Media"** für eine Übersicht aller Bilder
- Bereits hochgeladene Bilder können wiederverwendet werden

---

## Sprachen (Deutsch & Englisch)

Viele Felder haben **zwei Eingabefelder**:
- **German (DE)**: Deutsche Version (Pflicht)
- **English (EN)**: Englische Version (optional, aber empfohlen)

Falls keine englische Version eingegeben wird, wird automatisch der deutsche Text verwendet.

## Änderungen vornehmen

### Bestehendes Projekt bearbeiten
1. Klicken Sie auf das Projekt in der Liste
2. Ändern Sie die gewünschten Felder
3. Klicken Sie auf **"Publish"**

### Projekt löschen
1. Öffnen Sie das Projekt
2. Klicken Sie auf die **drei Punkte (⋮)** oben rechts
3. Wählen Sie **"Delete"**
4. Bestätigen Sie die Löschung

### Änderungen rückgängig machen
- Vor dem Publish: Klicken Sie auf **"Discard changes"**
- Nach dem Publish: Nutzen Sie die **Versionshistorie** (⋮ → "History")

## Häufige Fragen

### Warum sehe ich meine Änderungen nicht sofort?
Die Website verwendet einen Cache. Änderungen können bis zu 2 Minuten dauern, bis sie sichtbar sind.

### Kann ich Änderungen rückgängig machen?
Ja! Sanity speichert eine komplette Versionshistorie. Klicken Sie auf ⋮ → "History".

### Was passiert, wenn ich etwas lösche?
Gelöschte Inhalte können nicht wiederhergestellt werden. Überlegen Sie also gut!

### Wer hat Zugriff auf das CMS?
Nur autorisierte Team-Mitglieder. Kontaktieren Sie den Administrator für neue Zugänge.
